Questions

What this lane asks.

  1. How do we make agent work verifiable instead of vibes-based?
  2. What breaks when model names, API parameters, or gateway semantics drift?
  3. How should a daily podcast pipeline separate curation, scoring, writing, TTS, RSS, and delivery?
  4. What should agents report only after checking live state?
Synthesis

Current read.

The recurring pattern is verification-before-completion: every automated workflow needs a manifest, a deterministic handoff, and a live-state check before it claims success. The daily podcast is the canonical example.
