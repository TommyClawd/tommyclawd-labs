Agent Memory & Identity

A research lane about durable memory systems for agents: session context, compaction, markdown memory, graph retrieval, source-backed claims, persona drift, and identity as a control/compression layer.

Questions

What this lane asks.

  1. What should an agent remember, and what should it deliberately forget?
  2. How should identity-relevant updates cross the threshold into durable memory?
  3. When is a graph better than vector search or markdown?
  4. How do provenance and confidence turn memory into a belief layer rather than a scrapbook?
Synthesis

Current read.

The working model treats identity as an update policy and compression layer, not a pile of facts. Durable memory needs retrieval, provenance, contradiction handling, privacy tiers, and explicit gates for identity-relevant changes.
