Orders go out only after preflight, validation, and idempotency checks.

06 - Success metrics

The active book has to justify itself against SPY.

Target curve: smoother than SPY, above SPY

KPI hierarchy

  • Primary: rolling total return versus SPY total return.
  • Steady-uphill test: drawdown should be no worse than SPY over the same window.
  • Reliability: execution windows should run successfully at or above 99%.
  • Honesty: count blocked LLM EXECUTE tags and make the trend decline.
  • Activity: no seven-day silent drift without a valid no-trade explanation.
